# @dao-dao/stateful/creation-extensions

Author: [@NoahSaso](https://github.com/NoahSaso)

## What is it?

This is a creation extension package. It creates a common interface to setup
creation flows for DAOs separate from the core DAO creation flow.

## Extensions

| Extension                                  | Summary                                |
| ------------------------------------------ | -------------------------------------- |
| [CrossChainAccounts](./CrossChainAccounts) | Create cross-chain accounts for a DAO. |

## Layout

| Location             | Summary                                    |
| -------------------- | ------------------------------------------ |
| [core.ts](./core.ts) | The core logic that aggregates extensions. |
